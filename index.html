    The details.

    Storage
    Your notes live in a SQLite database in your user folder: ~/.cord on Windows and macOS, ~/.local/share/cord on Linux.
    Network
    Works offline. No online account and no telemetry. Cord checks GitHub for updates.
    Sync
    None yet. Your notes stay on the one computer.
    Lock screen
    Local accounts on your computer, unlocked with a PIN. The PIN keeps other people out of Cord. It does not encrypt your files.
    Structure
    Vaults keep separate work apart. Tags cut across the notes in a vault. Links connect any two notes.
    Writing
    Maths, tables, code highlighting, task lists, toggles, images and embeds. The editor is Shuttle.
    Source
    cord-note/cord under AGPL-3.0. Built with Tauri, Bun, React and SQLite.

    Not code-signed yet

    Windows and macOS will object the first time, because there is no certificate behind the installer. Updates are signed, and Cord checks them before installing.

    • Windows: SmartScreen calls it an unrecognised app. Choose More info, then Run anyway.
    • macOS: Gatekeeper refuses to open it. Right-click the app, choose Open, then confirm.
    • Linux: no warning. Mark the AppImage executable with chmod +x first.
